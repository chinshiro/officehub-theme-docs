# Theme Changelog

This document outlines the release history, new features, improvements, and bug fixes for the **TaboQ** Shopify theme.  
We recommend keeping your theme up to date to benefit from the latest enhancements and security updates.

> 💡 **Tip**: To update your theme, download the latest version from the [Shopify Theme Store](https://themes.shopify.com) and follow Shopify’s [theme update guide](https://help.shopify.com/en/manual/online-store/themes/theme-versions).

---

## [1.0] – 2025-03-01

### 🎉 Initial Release
- Fully responsive design with mobile-first approach.
- Built on **Tabler 1.3**, which is based on **Bootstrap 5.3** — as a result, TaboQ’s initial CSS foundation corresponds to **Bootstrap 5.0+** standards.
- Supports Shopify 2.0 theme architecture (sections everywhere).
- Built-in accessibility features (keyboard navigation, screen reader support).
- Optimized for Core Web Vitals and SEO.
- ✅ **Lightning Fast**: Optimized for **Core Web Vitals**—ensuring top performance and SEO rankings.
- 🎨 **Fully Customizable**: Over **80+ theme settings** with **Style Schemes** system, plus **30+ sections and blocks** for limitless design flexibility.
- 🌍 **Multi-language & Multi-currency Ready**: Sell globally with built-in support for multiple languages and currencies.
- 🌐 **One-Click Auto Translation**: Free integration with **Microsoft Translator (80+ languages)** and **Google Translate (130+ languages)**—no app required.
- ♿ **Accessibility Compliant**: Meets **WCAG 2.1 AA** standards for inclusive shopping experiences.
- 📱 **Mobile-First Responsive Design**: Flawless display on all devices—from smartphones to desktops.
- 💼 **B2B Features**: Built-in **quantity rules**, **volume pricing**, and wholesale-ready functionality.
- 🔍 **Hotspot Scene Imagery**: Showcase products in real-life contexts with interactive hotspot overlays that highlight key features.
- 📄 **Sidebar Layout Support**: Add sidebars to **Pages**, **Blog Index**, and **Blog Post** templates for enhanced content organization.
- 🗺️ **Auto-Generated Article Table of Contents**: Blog posts automatically generate a **clickable directory tree** from headings (H1–H6) for easy navigation.
- 📍 **Multi-Store Google Maps**: Display **multiple store locations** on an interactive map with search and address lookup.
- 🧊 **3D Model Integration**: Embed **GLB 3D models** on **any page type**—ideal for product demos, furniture, or tech gear.
- 🔎 **Predictive Search with Hot Links**: Enable **live search suggestions** as users type, plus customizable **“Popular Links”** for quick access.
- ⏳ **Countdown Timer**: Create urgency with a fully customizable **countdown component** for flash sales, launches, or limited offers.
