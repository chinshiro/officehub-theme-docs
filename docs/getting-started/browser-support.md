# Browser Support

Our theme fully supports the **latest three major versions** of each major browser.  
**Exception**: Safari, as its updates are tied to the operating system rather than released independently. For Safari, we guarantee support for **iOS 14 and later**. Note that visual rendering on iOS 14 may differ from newer versions, but the **full purchasing flow is guaranteed to function correctly**.

We do **not** provide support for issues caused by using unsupported browser versions. If you wish to add compatibility for older browsers, we recommend reviewing your store’s analytics to assess user impact and consider hiring a Shopify Expert.

## Desktop Browsers

- **Chrome**: Latest three versions (e.g., Chrome 133 and above)  
- **Firefox**: Latest three versions (e.g., Firefox 135 and above)  
- **Edge**: Latest three versions (e.g., Edge 133 and above)  
- **Safari**: From Safari 14.1 up to the latest version  

## Mobile Browsers

- **Chrome for Android**: Latest three versions (e.g., Chrome 133 and above)  
- **Firefox for Android**: Latest three versions (e.g., Firefox 135 and above)  
- **Edge for Android**: Latest three versions (e.g., Edge 133 and above)  
- **Safari on iOS**: From Safari 14.7 (iOS 14) up to the latest version  

## JavaScript Requirements

Certain interactive features—such as modals, mobile navigation menus, and product filtering—require **JavaScript to be enabled**.  

If JavaScript is disabled, we only guarantee the core purchasing flow:  
**Homepage → Product Page → Checkout**.  
All other functionality may be limited or unavailable without JavaScript.
