The **Default Blog** section is the main container for the `main-blog` template, used on blog index pages (e.g., `/blogs/news`). It displays a list of published articles with optional filtering, sharing, and layout controls.

## Settings

- **Full width**: Expand the blog page to 100% of the viewport width.  
- **Main section class**: Custom CSS class for the entire blog section (useful for spacing or custom styling).

### Breadcrumbs
- **Position**: Placement relative to page content (e.g., below title or above posts).  
- **Link color schema**: Text color for breadcrumb links, selected from **[Theme Settings → Basic Settings → Colors](/theme-settings/basic-settings#-4-colors)**.  
- **Alignment**: Horizontal alignment—`left`, `center`, or `right`.

## Child Blocks

### Page Top Banner  
> Controls the inner-page hero area (title, background image, overlay). Full settings: **[Blocks → Subblocks of Specific Block → Page Top Banner](/blocks/subblocks/page-top-banner)**.

### Blog Posts Lists  
> Renders the grid or list of blog articles with full customization options. For setting up blog posts cards, please refer to: **[Blocks → Specific Page Block → Blog Posts Lists](/blocks/specific-page-block/blog-posts-lists)**
