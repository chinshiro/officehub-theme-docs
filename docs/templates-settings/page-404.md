The **404 Page** section is the main container for the `main-404` template, displayed when a visitor lands on a broken or non-existent URL (e.g., `/page-that-does-not-exist`). It provides a user-friendly way to guide customers back to your store.

## Settings

- **Enable full width content**: Expand the 404 page content to 100% of the viewport width.  
- **Section class**: Custom CSS class for the entire 404 section (useful for spacing or custom styling).  
- **Background**: Set a solid or gradient background color.  
- **Or, use image**: Apply a background image using a preset from **[Theme Settings → Style scheme settings → Background Image Schema](/theme-settings/style-scheme-settings#%EF%B8%8F-2-background-image-schema)**.  
  > All four settings above follow: **[Blocks → Overview → General Settings](/blocks/overview#general-settings)** 
- **Text color schema**: Global text color for headings, messages, and links, selected from **[Theme Settings → Basic Settings → Colors](/theme-settings/basic-settings#-4-colors)**.

### Button Style
- **Style**: Visual appearance—`button` (solid) or `outline` (hollow).  
- **Color schema**: Button color from **[Theme Settings → Basic Settings → Colors](/theme-settings/basic-settings#-4-colors)**.  
- **Size**: `Small`, `Default`, or `Large`.
