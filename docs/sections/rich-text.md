The **Rich Text** section provides a clean, flexible container for displaying large blocks of formatted content—such as brand stories, policy details, editorial content, or instructional text. It supports a heading and a rich-text area with full formatting options (paragraphs, lists, links, bold/italic, etc.).

For full configuration details—including background styling, container width, and child block settings (heading and text)—see:  
**[Blocks → Composite Function Block → Rich Text](/blocks/composite-function-block/rich-text)**
