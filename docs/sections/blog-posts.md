# Blog Posts

The **Blog Posts** section displays a grid of articles from a selected blog anywhere on your store—ideal for homepages, landing pages, or dedicated content hubs. It supports responsive layouts, masonry grids, and rich card styling.

For full configuration details—including blog selection, layout options, card styling, and child block settings—see:  
**[Blocks → Composite Function Block → Blog Posts](/blocks/composite-function-block/blog-posts)**
