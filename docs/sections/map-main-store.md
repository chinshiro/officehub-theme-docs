The **Map Main Store** section displays your primary physical store location using an embedded Google Map, paired with your address, contact information, and optional call-to-action button. It’s ideal for brick-and-mortar businesses, flagship stores, or brands that want to emphasize local presence.

For full configuration details—including layout alignment, column widths, sticky behavior, and child block settings (heading, text, button, and store map)—see:  
**[Blocks → Composite Function Block → Map Main Store](/blocks/composite-function-block/map-main-store)**
