# Key features

## Supported blocks

Private blocks (file names start with `_`) cannot be added by hand — the section or parent block places them automatically. Their settings are documented right here:

- `_key-feature` — Key feature

### `_key-feature` — Key feature

#### Settings

| Setting | ID | Type | Default | Description |
|---|---|---|---|---|
| Block class | `class` | text |  |  |
| Panel color | `bg` | color | #e3e3e3 |  |
| Or, use a gradient | `bg_gradient` | color_background |  | Overrides the panel color above. |

#### Blocks inside Key feature

- [Image](/blocks/image) — `image`
- [Video](/blocks/video) — `video`
- [Steps](/blocks/steps) — `steps`
- [Heading](/blocks/heading) — `heading`
- [Text](/blocks/text) — `text`

## Settings

| Setting | ID | Type | Default | Description |
|---|---|---|---|---|
| Enable full width | `full_width` | checkbox | false |  |
| Text padding horizontal (mobile) | `text_padding_x_mob` | range | 0 | Spacing scale, 1 = 0.25rem (4px). |
| Text padding horizontal (desktop) | `text_padding_x` | range | 0 | Spacing scale, 1 = 0.25rem (4px). |
| Text padding vertical (mobile) | `text_padding_y_mob` | range | 4 | Spacing scale, 1 = 0.25rem (4px). |
| Text padding vertical (desktop) | `text_padding_y` | range | 6 | Spacing scale, 1 = 0.25rem (4px). |
| Block class | `class` | text |  |  |
