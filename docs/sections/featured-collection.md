The **Featured Collection** section highlights products from a selected collection or custom product list using a **Swiper-powered carousel** with advanced transition effects. It’s perfect for showcasing bestsellers, new arrivals, seasonal items, or promotional bundles in a visually dynamic way.

For full configuration details—including product source, carousel effects, autoplay, pagination styling, and responsive layout settings—see:  
**[Blocks → Composite Function Block → Featured Collection](/blocks/composite-function-block/featured-collection)**
