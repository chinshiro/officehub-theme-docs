# Background Video

The **Background Video** section displays a full-width or full-viewport video as a dynamic background, with optional overlaid text content (heading, description, and call-to-action button). It’s ideal for hero sections, brand storytelling, or immersive landing pages.

This section leverages the same robust configuration as the **Video With Text** block, including layout options, overlay styling, and video controls.

For complete setup instructions—including video settings, layout, overlay opacity, play button options, and child block configuration—see:  
**[Blocks → Composite Function Block → Video With Text](/blocks/composite-function-block/video-with-text)**
