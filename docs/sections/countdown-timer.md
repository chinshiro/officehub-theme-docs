The **Countdown Timer** section displays a dynamic countdown to a specific date and time—perfect for creating urgency around flash sales, product launches, or limited-time offers. It includes a fully configurable countdown block with customizable labels, styling, and layout options.

For complete setup instructions—including target date, time zone, label text, typography, color scheme, and layout—see:  
**[Blocks → Composite Function Block → Countdown Timer](/blocks/composite-function-block/countdown-timer)**
