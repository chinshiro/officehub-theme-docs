# Newsletter

## Supported blocks

These blocks can be added directly from the editor:

- [Heading](/blocks/heading) — `heading`
- [Text](/blocks/text) — `text`
- [Newsletter form](/blocks/newsletter-form) — `newsletter-form`

| Setting | ID | Type | Default | Description |
