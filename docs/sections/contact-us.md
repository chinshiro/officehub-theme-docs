The **Contact Us** section provides a ready-to-use layout for displaying a contact form alongside a heading and descriptive text. It can be added to any page—such as a dedicated contact page, footer, or sidebar—to help customers reach out with inquiries, support requests, or feedback.

For full configuration details—including form fields, styling, button settings, and child block options—see:  
**[Blocks → Composite Function Block → Contact Us](/blocks/composite-function-block/contact-us)**
