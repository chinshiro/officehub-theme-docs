# Carousel

The **Carousel** section implements a responsive, Bootstrap-based slideshow that supports **images**, **videos**, and **3D models** as slide content. Use it anywhere on your store to create engaging visual narratives, product showcases, or promotional banners.

For full configuration details—including autoplay, navigation controls, pagination styles, and child block settings—see:  
**[Blocks → Composite Function Block → Carousel](/blocks/composite-function-block/carousel)**
