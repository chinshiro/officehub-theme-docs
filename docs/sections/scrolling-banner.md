The **Scrolling Banner** section displays a continuously moving text banner—ideal for announcements, promotions, shipping notices, or live updates. It creates dynamic visual interest without requiring user interaction and is commonly used in headers, footers, or as a standalone promotional strip.

For full configuration details—including scroll direction (left, right, up, down), speed (interval), height settings, and child block options (heading and button)—see:  
**[Blocks → Composite Function Block → Scrolling Banner](/blocks/composite-function-block/scrolling-banner)**
