The **Multi Columns** section displays content in a responsive grid of cards—each combining an image, heading, text, and button. It’s ideal for showcasing features, services, product categories, testimonials, or any content that benefits from a clean, structured, multi-item layout.

For full configuration details—including column count (desktop/mobile), card styling, image cropping, and child block settings—see:  
**[Blocks → Composite Function Block → Multi Column](/blocks/composite-function-block/multi-column)**
