The **Custom Liquid** section allows you to embed raw Liquid, HTML, CSS, or JavaScript code directly into any page of your store. This is ideal for advanced customizations, third-party integrations, dynamic content rendering, or implementing logic that isn’t supported by standard blocks.

For full configuration details—including background settings, container width, and Liquid code input—see:  
**[Blocks → Composite Function Block → Custom Liquid Block](/blocks/composite-function-block/custom-liquid-block)**
