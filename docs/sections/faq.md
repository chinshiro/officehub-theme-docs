The **Faq** section displays a set of frequently asked questions with collapsible answers and an integrated keyword search bar—ideal for reducing support inquiries and improving user self-service. It supports an optional index sidebar for quick navigation in long FAQ lists.

For full configuration details—including index column, search functionality, styling, and child block settings—see:  
**[Blocks → Composite Function Block → Faq Collapsible Tabs](/blocks/composite-function-block/faq-collapsible-tabs)**
