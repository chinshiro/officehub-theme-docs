In the Scenario theme, every **Section** is a flexible container built from **Blocks**. You can freely add, reorder, and configure blocks within any section to create unique layouts—no coding required.

All sections are designed to be **modular, responsive, and performance-optimized**, giving you full creative control while maintaining speed and usability.

Below is the complete list of available sections. Click any link to view detailed settings and configuration options.

---

## 🧩 Available Sections

- [**Featured Collection**](/sections/featured-collection)  
  Showcase products from a collection in a responsive grid or carousel.

- [**Featured Product**](/sections/featured-product)  
  Display a single product with full media gallery, variant picker, and buy options.

- [**Rich Text**](/sections/rich-text)  
  Add custom headings, paragraphs, lists, and styled content.

- [**Image With Text**](/sections/image-with-text)  
  Combine images and text in flexible layouts (side-by-side, overlay, stacked).

- [**Slideshow**](/sections/slideshow)  
  Create full-width or contained carousels with images, video, or 3D models.

- [**Newsletter**](/sections/newsletter)  
  Embed a mailing list signup form with customizable styling.

- [**Custom Liquid**](/sections/custom-liquid)  
  Insert raw Liquid, HTML, or JavaScript for advanced customizations.

- [**3D Model With Text**](/sections/3d-model-with-text)  
  Display interactive 3D models alongside descriptive content.

- [**Background Video**](/sections/background-video)  
  Use a video as a full-width background with overlay text.

- [**Blog Posts**](/sections/blog-posts)  
  Feature recent articles from any blog in a card-based grid.

- [**Carousel**](/sections/carousel)  
  Build custom slideshows with mixed content (image, video, 3D, text).

- [**Contact Us**](/sections/contact-us)  
  Combine heading, text, and a contact form in one section.

- [**Countdown Timer**](/sections/countdown-timer)  
  Add urgency with a live countdown to sales, launches, or events.

- [**Faq**](/sections/faq)  
  Display collapsible frequently asked questions with optional search.

- [**General Section**](/sections/general-section)  
  A blank canvas for full creative freedom—add any combination of blocks.

- [**Hotspots**](/sections/hotspots)  
  Add interactive clickable points over an image (e.g., product details).

- [**Key Features**](/sections/key-features)  
  Highlight benefits or services with icons, headings, and short descriptions.

- [**Map Dealer Multi Store**](/sections/map-dealer-multi-store)  
  Show multiple store locations on an interactive map.

- [**Map Main Store**](/sections/map-main-store)  
  Display a single flagship store location with contact info.

- [**Multi Columns**](/sections/multi-columns)  
  Create responsive multi-column layouts (2–4 columns) with rich content.

- [**Product Description**](/sections/product-description)  
  Render the full product description (from Shopify admin) in any layout.

- [**Scrolling Banner**](/sections/scrolling-banner)  
  Display a continuously scrolling announcement bar (e.g., “Free shipping!”).

- [**Scrollspy Section**](/sections/scrollspy-section)  
  Create tabbed navigation that highlights as users scroll through content.

- [**Sidebar Section**](/sections/sidebar-section)  
  Build pages with a main content area and a customizable sidebar.

- [**Tabs Section**](/sections/tabs-section)  
  Organize content into switchable tabs (e.g., Specs, Shipping, Reviews).

- [**Testimonials**](/sections/testimonials)  
  Display customer reviews or quotes in a carousel or grid.

- [**Timelines**](/sections/timelines)  
  Visualize processes, milestones, or brand history in a vertical timeline.

- [**Video With Text**](/sections/video-with-text)  
  Pair embedded or uploaded videos with descriptive text and calls-to-action.
