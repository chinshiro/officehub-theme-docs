The **Hotspots** section displays an interactive image with multiple clickable or hoverable points that reveal contextual content—such as product details, descriptions, or calls to action. It’s ideal for lifestyle scenes, room layouts, product bundles, or any visual where users benefit from exploring specific areas.

For full configuration details—including desktop/mobile positioning, hotspot styling, content card behavior, and child block support—see:  
**[Blocks → Composite Function Block → Hotspots](/blocks/composite-function-block/hotspots)**
