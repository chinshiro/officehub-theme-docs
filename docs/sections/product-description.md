title: Product Description
sidebar_position: 51
---

The **Product Description** section displays the full product description as authored in **Shopify Admin > Products**. It is designed exclusively for use in **product templates** and allows you to insert the description directly as a standalone section—ideal for placing detailed content below media, above reviews, or within custom layouts.

This section has no configurable settings—it automatically renders the product’s rich-text description, including paragraphs, lists, images, and embedded media, exactly as entered in the Shopify admin.
