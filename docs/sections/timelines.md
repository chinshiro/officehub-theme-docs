The **Timelines** section presents content in a chronological, story-driven format—perfect for showcasing brand history, product development milestones, service workflows, or project roadmaps. Each timeline entry can include media (image, video, or 3D model), descriptive text, and custom icons, creating an engaging narrative experience.

For full configuration details—including icon selection, card styling, time label formatting, responsive column layout, and child block support—see:  
**[Blocks → Composite Function Block → Timelines](/blocks/composite-function-block/timelines)**
