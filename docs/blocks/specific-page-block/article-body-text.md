The **Article Body Text** block displays the full content of a blog post. It is **only available in blog post templates**.

## Article Body Text

- **Show date**: Display the article’s published date.  
- **Show author**: Show the name of the article’s author.  
- **Show X (formerly Twitter) sharing icon**: Enable the X/Twitter share button.  
- **Show Facebook sharing icon**: Enable the Facebook share button.  
- **Show excerpt**: Display the article’s excerpt (if defined in the Shopify admin).  
- **Show tags**: Show the blog post’s assigned tags.  
- **Tags style**: Styling for tags, using a preset from **[Theme Settings → Style scheme settings → Tags Style Schema](/theme-settings/style-scheme-settings#%EF%B8%8F-13-tags-style-schema)**.

## Prev / Next Link

- **Show prev/next link**: Display navigation to the previous and next blog posts.  
- **Style**: Visual style—`button`, `outline`, or `link`.  
- **Color schema**: Text/button color from theme color variables.  
- **Size**: Button size when style is `button` or `outline`—`small`, `default`, or `large`.

## Article Directory Tree

- **Show article directory tree**: Generate a table of contents from headings (`<h1>` to `<h6>`) in the article.  
- **Width**: Container width as a percentage (e.g., `25%`, `30%`).  
- **Position**: Placement of the directory—`left` or `right` sidebar.  
- **Style schema**: Card-style container for the directory, using a preset from **[Theme Settings → Style scheme settings → Cards Style Schema](/theme-settings/style-scheme-settings#-3-cards-style-schema)**.

## Comments

- **Style schema**: Overall styling for the comments section, using a **[Theme Settings > Style scheme theme-settings > Cards Style Schema](/theme-settings/style-scheme-settings#-3-cards-style-schema)** preset.  
- **Number per page**: Maximum number of comments displayed per page.  
- **Paging**: Pagination method—`Infinite scroll` or `Show buttons`.  
	- **Infinite scroll**: Automatically load the next page when scrolling
	- **Show buttons**: Display pagination button
- **Item color**: Background or text color for individual comment blocks, selected from theme color variables.  
- **Show comment name**: Display the commenter’s name.  
- **Show comment date**: Show the date the comment was posted.  
- **Input style schema**: Styling for the comment input field, from **[Theme Settings → Style scheme settings → Input Style Schema](/theme-settings/style-scheme-settings#%EF%B8%8F-9-input-style-schema)**.  
- **Button style**: Submit button appearance—`button`, `outline`.  
- **Button color schema**: Button color from **[Theme Settings → Basic Settings → Colors](/theme-settings/basic-settings#-4-colors)**.  
- **Button size**: `small`, `default`, or `large`.  
- **Button alignment**: Horizontal alignment of the submit button (left, center, right).
