# Product Description

The **Product Description** block displays the product’s full description as entered in **Shopify Admin > Products**. It is **only available in product templates** and must be added manually within other sections (e.g., a custom content section below the product media).

- **Enable full width**: Expand the description container to 100% of the viewport width (ignoring the site’s maximum content width).  
- **Class**: Custom CSS class for the container—commonly used to apply spacing utilities (e.g., `mt-6`, `pb-4`). For guidance, see: **[Blocks → Overview → General Settings](/blocks/overview#general-settings)**.
