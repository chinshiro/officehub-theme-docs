A subscription form block for collecting email addresses. Add this block to any section or layout where you want to encourage visitors to join your mailing list.

## Main Parameters

- **Block class**: Custom CSS class applied to the block container for additional styling or spacing control. **[Blocks → Overview → General Settings](/blocks/overview#general-settings)** 

- **Input prompt text (placeholder)**: The placeholder text shown inside the email input field (e.g., “Enter your email”).

- **Input style**: Styling preset for the email input field.  
  → Defined in **[Theme Settings → Style scheme settings → Input Style Schema](/theme-settings/style-scheme-settings#%EF%B8%8F-9-input-style-schema)**

- **Width**: Width of the form container as a percentage of its parent (e.g., `100%`, `50%`).

- **Alignment**: Horizontal alignment within the parent container (left, center, or right).

- **Show button label**: Choose what appears on the submit button:  
  - `Icon`: Display only an icon (e.g., arrow or envelope)  
  - `Text`: Display only text (e.g., “Subscribe”)  
  - `Both`: Show both icon and text

## Animations on Scroll
- Enable entrance animations as block enter the viewport.  
- Configuration follows the standard **Animations on Scroll** settings.  
- See: **[Blocks → Overview → Animations on scroll](/blocks/overview#animations-on-scroll)**
