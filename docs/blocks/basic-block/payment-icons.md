A block for displaying payment method icons (e.g., credit cards, digital wallets) to build trust and clarify accepted payment options.

## Main Parameters

- **Icons**:  
  Enter payment icon codes in **lowercase**, separated by commas.  
  **Supported icons**:  
  ```
  shopify, paypal, visa, mastercard, maestro,discover,jcb,stripe,amazon,americanexpress,klarna,applepay,okpay,payoneer,unionpay,westernunion,bitcoin,2checkout,alipay,bancontact,bitpay,blik,cirrus,clickandbuy,coinkite,dinersclub,directdebit,dotpay,dwolla,ebay,eway,giropay,googlewallet,ingenico,laser,mir,monero,neteller,ogone,paybox,paymill,payone,paysafecard,payu,payza,przelewy24,ripple,sage,sepa,skrill,solo,square,switch,tpay,ukash,verifone,verisign,webmoney,worldpay
  ```
  > 💡 **Dark variant**: Append `-dark` to any icon code to use a dark-themed version (e.g., `shopify-dark`, `paypal-dark`).

- **Size**:  
  Choose from 6 predefined sizes:  
  `Extra Small`, `Small`, `Medium`, `Large`, `Extra Large`, `2 Extra Large`

- **Alignment (desktop)**:  
  Horizontal alignment on desktop (left, center, right).

- **Alignment (mobile)**:  
  Horizontal alignment on mobile devices.
