A simple block to display your physical store location using Google Maps. Ideal for contact pages or store locator sections.

## Store Map Parameters

- **Store image**: An optional image of your storefront or interior (e.g., shop exterior, logo, or team photo).  
- **Image width**: Width of the image container as a percentage of its parent (e.g., `50%`, `100%`).  
- **Store map**: Embed code or coordinates for your store location.  
  → For **free usage**, use the **shareable Google Maps link** (e.g., from Google Maps “Share” > “Embed a map” or copy the URL).  
  → The block will parse the coordinates or iframe from the provided input and render the map accordingly.  
  → No API key required for basic static embedding (subject to Google’s free-tier usage limits).

> ⚠️ **Note**: For advanced features (e.g., custom markers, interactivity, or multiple locations), use the **[Dealer Multi Store Map](/blocks/basic-block/dealer-multi-store-map)** block with a Google Maps API key.
