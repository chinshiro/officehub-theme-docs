# Map store

## Settings

| Setting | ID | Type | Default | Description |
|---|---|---|---|---|
| Block class | `class` | text |  |  |
| Map embed code | `store_map` | html |  | Paste the full iframe code from Google Maps. For multiple markers, use a custom map from google.com/mymaps (Share &gt; Embed map) instead of a single-place link. Only rendered when an embed is set. |
| Image | `store_image` | image_picker |  | Shown next to the map on desktop. |
| Image ratio | `image_ratio` | select |  |  |
| Image width | `image_width` | range | 40 |  |

### Option values

- **Image ratio** (`image_ratio`): Auto (``), Custom (3:1) (`3.0`), Ultrawide (21:9) (`2.33`), Double-width (2:1) (`2.0`), Widescreen/HD (16:9) (`1.78`), Classic/DSLR (3:2) (`1.5`), ISO Paper (1.4:1) (`1.4`), Standard Definition/SD (4:3) (`1.33`), Landscape (5:4) (`1.25`), Square (1:1) (`1.0`), Instagram Portrait (4:5) (`0.8`), Portrait Photography (3:4) (`0.75`), Pinterest Pin Ratio (2:3) (`0.67`), Portrait (9:16) (`0.56`)
