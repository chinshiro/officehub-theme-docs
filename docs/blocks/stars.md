# Stars

## Settings

| Setting | ID | Type | Default | Description |
|---|---|---|---|---|
| Block class | `class` | text | mb-4 |  |
| Rating | `rating` | range | 5 | Number of filled stars. Supports half steps. |
| Star size in rem (1 = 16px) | `star_size` | range | 1 |  |
| Inactive color | `color` | select | gray-300 |  |
| Custom inactive color | `color_custom` | color | #d1d5db | Used when Inactive color is set to Custom. |
| Active color | `color_active` | select | warning |  |
| Custom active color | `color_active_custom` | color | #fbbf24 | Used when Active color is set to Custom. |
| Alignment (desktop) | `alignment` | text_alignment | left |  |
| Alignment (mobile) | `alignment_mob` | text_alignment | left |  |
