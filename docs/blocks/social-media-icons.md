# Social media icons

## Settings

| Setting | ID | Type | Default | Description |
|---|---|---|---|---|
| Block class | `class` | text |  |  |
| Icons | `icons` | text | facebook, x, instagram, youtube |  |
| Icon size | `icons_size` | range | 100 |  |
| Gap between icons | `gap` | range | 3 | Spacing scale, 1 = 0.25rem (4px). gap only supports 0-10. |
| Alignment (desktop) | `alignment` | text_alignment | center |  |
| Alignment (mobile) | `alignment_mob` | text_alignment | center |  |
| Icon and link color | `color` | color |  |  |
| Hover color | `hover_color` | color |  | Color on hover. Leave empty to keep the icon/link color. |
| Show labels | `show_label` | checkbox | false |  |
| Show border | `show_border` | checkbox | false |  |
| Border padding | `border_padding` | range | 2 | Spacing scale, 1 = 0.25rem (4px). Only used when the border is on. |
| Border radius | `border_radius` | select | rounded-full |  |

### Option values

- **Border radius** (`border_radius`): Square (`rounded-none`), Rounded small (`rounded-md`), Rounded medium (`rounded-xl`), Rounded large (`rounded-2xl`), Rounded extra large (`rounded-3xl`), Squircle (`rounded-squircle`), Circle (`rounded-circle`), Pill (`rounded-full`), Rounded top (`rounded-top`), Rounded bottom (`rounded-bottom`), Single corner (`rounded-corner`), Diagonal corners (`rounded-diagonal`), Arch (`rounded-arch`), Dome (`rounded-dome`), Cylinder (`rounded-cylinder`), Barrel (`rounded-barrel`), Leaf pointed (`rounded-leaf-point`), Leaf (`rounded-leaf`), Lens (`rounded-lens`), Petal (`rounded-petal`), Egg (`rounded-egg`), Egg inverted (`rounded-egg-inverted`), Shield (`rounded-shield`), Drop (`rounded-drop`), Diamond (`rounded-diamond`), Blob (`rounded-blob`), Amoeba (`rounded-amoeba`), Flower (`rounded-flower`), Mountain (`rounded-mountain`), Pebble (`rounded-pebble`), Bean (`rounded-bean`), Cloud (`rounded-cloud`)
