The **Key Features** block creates an immersive, scroll-driven experience where each feature section dynamically changes the background as users navigate. Ideal for storytelling, product showcases, or highlighting core brand values.

## Settings

- **Enable full width**: Expand the entire block container to 100% of the viewport width.

## Child Blocks – Key Feature

Each **Key Feature** represents a single scrollable section with its own visual identity.

### Settings
- **Enable full width**: Make this individual feature span the full viewport width (independent of parent block).  
- **Background**: Set a solid background color.  
- **Background gradient**: Apply a custom gradient (overrides solid background if both are set).

### Supported Child Blocks
You can add any combination of the following within each **Key Feature**:

#### Image
> Static image with full styling controls.  Settings follow **[Blocks → Basic Block → Image](/blocks/basic-block/image)**.  

#### 3D model
> Interactive GLB/GLTF model. Settings follow **[Blocks → Basic Block → 3D model](/blocks/basic-block/3d-model)**.  

#### Video
> Embedded or self-hosted video. Settings follow **[Blocks → Basic Block → Video](/blocks/basic-block/video)**.  

#### Steps segments
> Visual progress or process indicator (e.g., “Step 1 of 3”). Settings follow **[Blocks → Basic Block → Steps segments](/blocks/basic-block/steps-segments)**.  

#### Heading
> Section title with typography and color controls. Settings follow **[Blocks → Basic Block → Heading](/blocks/basic-block/heading)**.  

#### Text
> Rich-text description or supporting content. Settings follow **[Blocks → Basic Block → Text](/blocks/basic-block/text)**.  

> 🌟 **Tip**: Use contrasting background colors or gradients between consecutive **Key Feature** blocks to create a striking visual rhythm as users scroll.
