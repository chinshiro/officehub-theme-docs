# Map Main Store

The **Map Main Store** block displays your physical store location with an embedded map and address information. Ideal for brick-and-mortar businesses or brands with flagship locations.

## Settings

- **Enable full width**: Expand the block to 100% of the viewport width.  
- **Block class**: Custom CSS class for spacing or layout overrides.  
- **Background**: Set a solid or gradient background color.  
- **Or, use image**: Apply a background image using a preset from **[Theme Settings → Style scheme settings → Background Image Schema](/theme-settings/style-scheme-settings#%EF%B8%8F-2-background-image-schema)**.  
  > All four settings above follow: **[Blocks → Overview → General Settings](/blocks/overview#general-settings)** 
- **Horizontal alignment**: Align the entire block content—`Left`, `Center`, or `Right`.  
- **Vertical alignment**: Vertical positioning within the container—`Top`, `Center`, or `Bottom`.

## Store Address Block

Displays your store’s contact details in a dedicated column.

- **Column class**: CSS class for the address column container.  
- **Column width**: Width of the address column as a percentage (e.g., `40%`).  
- **Enable sticky top**: Keep the address column fixed at the top while scrolling.

### Child Blocks

#### Heading
> Store name or section title (e.g., “Visit Us”). Settings follow **[Blocks → Basic Block → Heading](/blocks/basic-block/heading)**.  

#### Text
> Full address, phone, email, or hours. Settings follow **[Blocks → Basic Block → Text](/blocks/basic-block/text)**.  

#### Button
> Call-to-action (e.g., “Get Directions”). Settings follow **[Blocks → Basic Block → Button](/blocks/basic-block/button)**.

## Map Location Block

Houses the interactive map.

- **Column class**: CSS class for the map column container.  
- **Column width**: Width of the map column as a percentage (e.g., `60%`).  
- **Enable sticky top**: Keep the map column fixed at the top while scrolling.

### Child Block

#### Store map
> Embedded Google Maps or static map. Full settings follow **[Blocks → Basic Block → Store Map](/blocks/basic-block/store-map)**.
