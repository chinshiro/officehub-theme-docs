The **Testimonials** block displays customer reviews or endorsements in a visually engaging carousel format. Ideal for building trust and social proof on homepages, product pages, or landing sections.

## Settings

- **Enable full width**: Expand the block to 100% of the viewport width.  
- **Block class**: Custom CSS class for spacing or layout overrides.  
- **Background**: Set a solid or gradient background color.  
- **Or, use image**: Apply a background image using a preset from **[Theme Settings → Style scheme settings → Background Image Schema](/theme-settings/style-scheme-settings#%EF%B8%8F-2-background-image-schema)**.  
  > All four settings above follow: **[Blocks → Overview → General Settings](/blocks/overview#general-settings)**

**Testimonials**
- **Enable auto play**: Automatically cycle through testimonials.  
- **Interval**: Time between slides in milliseconds (e.g., `5000` = 5 seconds).

## Child Blocks

### Heading
Section title (e.g., “What Our Customers Say”). Settings follow **[Blocks → Basic Block → Heading](/blocks/basic-block/heading)**.

### Testimonial  
Each individual testimonial card in the carousel.

#### Settings
- **Enable full width**: Expand the block to 100% of the viewport width.  
- **Block class**: Custom CSS class for spacing or layout overrides.  
- **Background**: Set a solid or gradient background color.  
- **Or, use image**: Apply a background image using a preset from **[Theme Settings → Style scheme settings → Background Image Schema](/theme-settings/style-scheme-settings#%EF%B8%8F-2-background-image-schema)**.  
  > All four settings above follow: **[Blocks → Overview → General Settings](/blocks/overview#general-settings)**
- **Horizontal alignment**: `Left`, `Center`, or `Right`.  
- **Vertical alignment**: `Top`, `Center`, or `Bottom`.

#### Child Blocks
##### Stars
> Rating stars (e.g., ★★★★☆). Settings follow standard rating components. Settings follow **[Blocks → Basic Block → Stars](/blocks/basic-block/stars)**. 

##### Heading
> Reviewer name or title (e.g., “Sarah T., Verified Buyer”).  Settings follow **[Blocks → Basic Block → Heading](/blocks/basic-block/heading)**. 

##### Text
> The testimonial quote or review content. Settings follow **[Blocks → Basic Block → Text](/blocks/basic-block/text)**. 

##### Video
> Optional video testimonial (MP4, YouTube, Vimeo). Settings follow **[Blocks → Basic Block → Video](/blocks/basic-block/video)**.  

##### Image
> Reviewer photo or brand logo. Settings follow **[Blocks → Basic Block → Image](/blocks/basic-block/image)**. 

> 💡 **Tip**: For best results, keep testimonials concise and include real names, photos, or videos to enhance authenticity.
