The **Blog Posts** block displays a grid of blog article cards from a selected blog. It is commonly used in homepage sections, landing pages, or custom layouts to feature recent content.

## Settings

- **Enable full width**: Expand the block to 100% of the viewport width.  
- **Blog class**: Custom CSS class for spacing or layout overrides.  
- **Background**: Set a solid or gradient background color.  
- **Or, use image**: Apply a background image using a preset from **[Theme Settings → Style scheme settings → Background Image Schema](/theme-settings/style-scheme-settings#%EF%B8%8F-2-background-image-schema)**.  
  > All four settings above follow: **[Blocks → Overview → General Settings](/blocks/overview#general-settings)** 
- **Blog**: Select the blog (e.g., “News”, “Journal”) whose posts you want to display.  
- **Limit**: Maximum number of blog posts to show.  
- **Per row on desktop**: Number of cards per row on desktop (e.g., 2, 3, 4).  
- **Per row on mobile**: Number of cards per row on mobile (typically 1 or 2).  
- **Enable masonry**: Toggle masonry layout for variable-height cards (useful when post titles or excerpts vary in length).

## Child Blocks

- **Blog posts cards**: Configure the appearance of each article card (image, title, excerpt, date, etc.). Settings follow **[Blocks → Subblocks of Specific Block → Blog Posts Cards](/blocks/subblocks/blog-posts-cards)**.  
- **Heading**: Add a section title above the blog grid. Settings follow **[Blocks → Basic Block → Heading](/blocks/basic-block/heading)**.  
- **Text**: Include a descriptive paragraph or call-to-action below the heading. Settings follow **[Blocks → Basic Block → Text](/blocks/basic-block/text)**.
