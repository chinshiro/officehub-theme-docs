Recommended Products block settings

## Heading  
Used to set the top heading of the block.  
For detailed parameters, refer to: **[Blocks → Basic Block → Heading](/blocks/basic-block/heading)**

## Text  
Appears below the heading and supports rich text content (e.g., descriptions, calls to action).  
For configuration options, refer to: **[Blocks → Basic Block → Text](/blocks/basic-block/text)**

## Products  
Define which products to display:

- **From collection**: Pull products from a specific collection. Select the desired collection.  
- **Or, from products**: Manually select individual products to feature.  
- **Limit**: Maximum number of products to show.  
- **Per row on desktop**: Number of products displayed per row on desktop (e.g., 2, 3, 4, 5).  
- **Per row on mobile**: Number of products per row on mobile devices (typically 1 or 2).

## Product cards  
Customize the appearance and behavior of each product card (e.g., image ratio, price display, swatches, badges).  
For full parameter details, refer to: **[Blocks → Subblocks of Specific Block → Product Cards](/blocks/subblocks/product-cards)**

## Animations on Scroll
- Enable entrance animations as block enter the viewport.  
- Configuration follows the standard **Animations on Scroll** settings.  
- See: **[Blocks → Overview → Animations on scroll](/blocks/overview#animations-on-scroll)**
