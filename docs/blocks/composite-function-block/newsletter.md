The **Newsletter** block collects email subscriptions from visitors. It’s a key tool for building your marketing list and driving repeat traffic through email campaigns.

## Settings

- **Enable full width**: Expand the block to 100% of the viewport width.  
- **Block class**: Custom CSS class for spacing or layout overrides.  
- **Background**: Set a solid or gradient background color.  
- **Or, use image**: Apply a background image using a preset from **[Theme Settings → Style scheme settings → Background Image Schema](/theme-settings/style-scheme-settings#%EF%B8%8F-2-background-image-schema)**.  
  > All four settings above follow: **[Blocks → Overview → General Settings](/blocks/overview#general-settings)**

### Content
- **Width**: Width of the content container as a percentage (e.g., `100%`, `80%`, `600px` equivalent via responsive scaling).

## Child Blocks

### Heading
> Section title (e.g., “Join Our Newsletter”). Settings follow **[Blocks → Basic Block → Heading](/blocks/basic-block/heading)**.  

### Text
> Supporting description (e.g., “Get early access to sales and new arrivals”). Settings follow **[Blocks → Basic Block → Text](/blocks/basic-block/text)**.  

### Newsletter form
> Email input field with submit button. Settings follow **[Blocks → Basic Block → Newsletter Form](/blocks/basic-block/newsletter-form)**.
