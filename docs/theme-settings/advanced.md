# Advanced

## Settings

| Setting | ID | Type | Default | Description |
|---|---|---|---|---|
| Button hover animations | `button_hover_animation` | checkbox | false | Solid: a white sheen sweeps across. Outline/Ghost: the fill slides in like a progress bar and gradients flow while hovered. |

> 💡 Available under **Theme settings** in the editor.
