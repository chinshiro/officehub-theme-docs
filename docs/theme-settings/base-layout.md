# Base / Layout

## Settings

| Setting | ID | Type | Default | Description |
|---|---|---|---|---|
| Base font size (1rem) | `base_font_size` | range | 16 | Global base for all rem-based spacing/typography |
| Container max width | `container_max_width` | range | 1320 |  |
| Container horizontal gutter | `container_gutter` | number | 1.5 | Side padding for container (rem) |
| Block inner spacing (mobile) | `blk_space_y_mob` | range | 24 | Vertical padding added by the 'Enable spacing' toggle on every block and section (mobile). |
| Block inner spacing (desktop) | `blk_space_y_desk` | range | 40 | Vertical padding added by the 'Enable spacing' toggle on every block and section (desktop, 1024px and up). |

> 💡 Available under **Theme settings** in the editor.
