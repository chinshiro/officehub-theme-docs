# Swatches

## Settings

| Setting | ID | Type | Default | Description |
|---|---|---|---|---|
| Swatches source | `swatches_source` | select | theme |  |
| Swatches option name | `swatches_option_name` | text | Color,Colour,Couleur,Farbe | Separate options with a comma. Case-sensitive. E.g. Color,Couleur,Farbe |
| Variant images first | `swatches_variant` | checkbox | true | When enabled, the variant image is displayed first. If the variant is not set, will be matched from the swatch color list below. |
| Swatches image crop alignment | `swatches_crop_align` | select | center |  |
| Swatch color list | `swatches_value_list` | textarea |  | One color per line. Example: Red:#ff0000. Up to three colors can be used to show vertical stripes. Example: Red Blue Stripes:#e22#22e |

### Option values

- **Swatches source** (`swatches_source`): No (`none`), Shopify (`native`), Theme (`theme`)
- **Swatches image crop alignment** (`swatches_crop_align`): Top (`top`), Middle (`center`), Bottom (`bottom`)

> 💡 Available under **Theme settings** in the editor.
