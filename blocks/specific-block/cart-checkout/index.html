Cart Checkout

The Cart Checkout block displays the checkout form inside the cart sidebar or cart page, including subtotal, order notes, policies, and action buttons.

Cart Checkout Settings​

  • Show order note: Toggle visibility of the order note input field.
  • Order note collapsed: Collapse the order note input by default (users can expand it to write).
  • Show tax status and shipping policy link: Display links to your tax and shipping policy pages.
  • Show additional checkout options: Show Shopify’s accelerated checkout buttons (e.g., Shop Pay, PayPal, Apple Pay).
  • Terms and conditions link: URL to your store’s terms and conditions page.
  • Terms checkbox checked: Require customers to check a box to agree to terms before checkout.
  • Enable direct checkout: Skip the cart page and go straight to checkout when “Checkout” is clicked.

Style​

  • Price color schema: Color scheme for the Subtotal price. Defined in Theme Settings → Style scheme settings → Price Style Schema.
  • Subtotal size: Font size of the subtotal text.
  • Order note color schema: Text color for the “Order note” heading. Uses color variables from Theme Settings → Basic Settings → Colors.
  • Form style: Styling for the order note text area. Select a preset from Theme Settings → Style scheme settings → Form Style Schema.

Checkout Button​

  • Style: Visual style—button (solid) or outline (hollow).
  • Color schema: Button color from your theme’s color variables.
  • Size: Button size—small, default, or large.
