Currency Language

The Currency & Language block allows you to insert currency and language switchers anywhere on your page—ideal for localized shopping experiences.

Country/Currency​

  • Enable country/currency selector: Toggle visibility of the currency switcher.
  • Show country flag: Display the country flag next to each currency option.
  • Show country name: Show the full country name alongside the currency (e.g., “United States – USD”).

Language​

  • Enable language selector: Toggle visibility of the language switcher.
  • Show country flag: Display the country flag next to each language option (e.g., 🇺🇸 for English, 🇫🇷 for French).

Selector Style​

  • Selector style: Apply a predefined styling scheme for the main selector button.
    → Defined in Theme Settings → Style scheme settings → Selector Style Schema.
  • Dropdown style: Apply a styling scheme for the dropdown menu that appears when the selector is opened.
    → Defined in Theme Settings → Style scheme settings → Dropdown Style Schema.
